# 文言实词整理

## B

<span style="color:rgb(192, 0, 0)">彼</span>：那（寘彼周行 卷耳）

## C

采采：茂盛鲜明的样子（采采卷耳）
<span style="color:rgb(192, 0, 0)">参差</span>：<span style="color:rgb(192, 0, 0)">长短不齐</span>（参差荇菜）
<span style="color:rgb(192, 0, 0)">崔嵬</span>：<span style="color:rgb(192, 0, 0)">高山</span>（至彼崔嵬）

## F

<span style="color:rgb(192, 0, 0)">反侧</span>：<span style="color:rgb(192, 0, 0)">翻来覆去</span>（辗转反侧）
服：想（寤寐思服）

## G

<span style="color:rgb(192, 0, 0)">姑</span>：<span style="color:rgb(192, 0, 0)">姑且</span>（我姑酌彼金罍 卷耳）
关关：鸟的和鸣声（关关雎鸠，在河之洲）

## H

怀：想念（卷耳：嗟我怀人 维以不永怀）

## J

雎鸠：一种水鸟（关关雎鸠，在河之洲）
砠：有土的石山（陟彼砠矣 卷耳）

## L

流：顺水之流而取（左右流之）

## M

芼：选择（左右芼之）
<span style="color:rgb(192, 0, 0)">寐</span>：<span style="color:rgb(192, 0, 0)">睡着了</span>（寤寐求之）

## Q

琴瑟：都是古代的乐器。琴有五弦或七弦，瑟有二十五弦。（琴瑟友之）
<span style="color:rgb(192, 0, 0)">逑</span>：<span style="color:rgb(192, 0, 0)">配偶</span>（君子好逑）

## S

淑：品德好（窈窕淑女）

## W

维：句首语气词（维以不永怀 卷耳）
<span style="color:rgb(192, 0, 0)">寤</span>：<span style="color:rgb(192, 0, 0)">睡醒</span>（寤寐思服）

## X

荇：一种水草，可以吃（参差荇菜）
<span style="color:rgb(192, 0, 0)">吁</span>：<span style="color:rgb(192, 0, 0)">忧愁</span>（云何吁矣 卷耳）

## Y

窈窕：美好的样子（窈窕淑女）
以：介词 借（此）（维以不永怀 卷耳）
<span style="color:rgb(192, 0, 0)">盈</span>：<span style="color:rgb(192, 0, 0)">满</span>（不盈顷筐）
永：长（维以不永怀 卷耳）
悠：思（悠哉悠哉）
友：亲爱（琴瑟友之，这里名作动，用琴瑟作乐来表达爱她之意）
云：语气词（云何吁矣 卷耳）

## Z

<span style="color:rgb(192, 0, 0)">辗转</span>：<span style="color:rgb(192, 0, 0)">转动</span>（辗转反侧）
<span style="color:rgb(192, 0, 0)">酌</span>：<span style="color:rgb(192, 0, 0)">斟酒喝</span>（我姑酌彼金罍 卷耳）
寘：放（寘彼周行 卷耳）
<span style="color:rgb(192, 0, 0)">陟</span>：<span style="color:rgb(192, 0, 0)">登</span>（陟彼崔嵬 卷耳）
<span style="color:rgb(192, 0, 0)">洲</span>：<span style="color:rgb(192, 0, 0)">水中的陆地</span>（关关雎鸠，在河之洲）
周行：大道（寘彼周行 卷耳）
