# 你好，世界

这是这个博客的第一篇文章。

## 为什么还要写博客

现在写东西的地方太多了：社交平台、笔记软件、各种专栏。但用了一阵子之后，
总觉得缺了点什么：

- **内容会被时间冲走。** 平台的推荐流永远只关心最新的东西，三年前写下的思考，
  除非特意去翻，否则再也不会被看见。
- **格式不由自己决定。** 想加一个表格，或者嵌一段代码高亮，往往要跟编辑器搏斗。
- **数据不在自己手里。** 平台关闭、账号异常、规则变更，积累的内容可能一夜之间就没了。

自建博客正好解决这三点：内容是普通的文本文件，格式完全由自己控制，
仓库握在自己手里，而托管是免费的。

## 为什么选择静态站点

我不需要评论、不需要后台、不需要数据库。我只是想把 Markdown 文件变成网页，
所以静态站点生成器正好合适：

1. 写作时只关心内容，不关心样式；
2. 构建产物是纯 HTML，加载快，也不会有服务端漏洞；
3. 用 Git 管理，每次修改都有记录，写错了随时回退。

## 接下来写什么

大致会围绕这几类：

| 类型 | 说明 |
| --- | --- |
| 技术笔记 | 踩过的坑、读过的源码、项目的设计取舍 |
| 工具使用 | 提效的配置、脚本、工作流 |
| 随笔 | 与技术无关，但想留下来的想法 |

::tip 小提示
按 <kbd>Ctrl</kbd> + <kbd>K</kbd>（macOS 上是 <kbd>⌘</kbd> + <kbd>K</kbd>）可以呼出搜索框。
::

那么，开始吧。
