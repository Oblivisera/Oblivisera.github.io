# 文言实词整理（王力古代汉语）

## B

### 彼：
1.<span style="color:rgb(192, 0, 0)">那</span>。例：寘彼周行。（《卷耳》）  

## C

### 采采：
1.茂盛鲜明的样子。例：采采卷耳。（《卷耳》）  

### 参差：
1.<span style="color:rgb(192, 0, 0)">长短不齐</span>。例：参差荇菜。（《关雎》）  

### 崔嵬：
1.<span style="color:rgb(192, 0, 0)">高山</span>。例：陟彼崔嵬。（《卷耳》）  

## F

### 反侧：
1.<span style="color:rgb(192, 0, 0)">翻来覆去</span>。例：辗转反侧。（《关雎》）  

### 服：
1.想。例：寤寐思服。（《关雎》）  

## G

### 姑：
1.<span style="color:rgb(192, 0, 0)">姑且</span>。例：我姑酌彼金罍。（《卷耳》）  

### 关关：
1.鸟的和鸣声。例：关关雎鸠，在河之洲。（《关雎》）  

## H

### 怀：
1.想念。例：嗟我怀人 维以不永怀。（《卷耳》）  

## J

### 砠：
1.有土的石山。例：陟彼砠矣。（《卷耳》）  

### 雎鸠：
1.一种水鸟。例：关关雎鸠，在河之洲。（《关雎》）  

## L

### 流：
1.顺水之流而取。例：左右流之。（《关雎》）  

## M

### 芼：
1.选择。例：左右芼之。（《关雎》）  

### 寐：
1.<span style="color:rgb(192, 0, 0)">睡着了</span>。例：寤寐求之。（《关雎》）  

## Q

### 琴瑟：
1.都是古代的乐器。琴有五弦或七弦，瑟有二十五弦。例：琴瑟友之。（《关雎》）  

### 逑：
1.<span style="color:rgb(192, 0, 0)">配偶</span>。例：君子好逑。（《关雎》）  

## S

### 淑：
1.品德好。例：窈窕淑女。（《关雎》）  

## W

### 维：
1.句首语气词。例：维以不永怀。（《卷耳》）  

### 寤：
1.<span style="color:rgb(192, 0, 0)">睡醒</span>。例：寤寐思服。（《关雎》）  

## X

### 荇：
1.一种水草，可以吃。例：参差荇菜。（《关雎》）  

### 吁：
1.<span style="color:rgb(192, 0, 0)">忧愁</span>。例：云何吁矣。（《卷耳》）  

## Y

### 窈窕：
1.美好的样子。例：窈窕淑女。（《关雎》）  

### 以：
1.介词 借（此）。例：维以不永怀。（《卷耳》）  

### 盈：
1.<span style="color:rgb(192, 0, 0)">满</span>。例：不盈顷筐。（《卷耳》）  

### 永：
1.长。例：维以不永怀。（《卷耳》）  

### 友：
1.亲爱。这里名作动，用琴瑟作乐来表达爱她之意。例：琴瑟友之。（《关雎》）  

### 悠：
1.思。例：悠哉悠哉。（《关雎》）  

### 云：
1.语气词。例：云何吁矣。（《卷耳》）  

## Z

### 辗转：
1.<span style="color:rgb(192, 0, 0)">转动</span>。例：辗转反侧。（《关雎》）  

### 寘：
1.放。例：寘彼周行。（《卷耳》）  

### 陟：
1.<span style="color:rgb(192, 0, 0)">登</span>。例：陟彼崔嵬。（《卷耳》）  

### 洲：
1.<span style="color:rgb(192, 0, 0)">水中的陆地</span>。例：关关雎鸠，在河之洲。（《关雎》）  

### 周行：
1.大道。例：寘彼周行。（《卷耳》）  

### 酌：
1.<span style="color:rgb(192, 0, 0)">斟酒喝</span>。例：我姑酌彼金罍。（《卷耳》）
